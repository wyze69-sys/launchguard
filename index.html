Solana Risk Screening

Paste a Solana token mint. Get a risk report you can verify.

A "mint" is a token's unique address on Solana — paste that address, not a wallet address. The score runs 0 to 100: higher means riskier. The cluster selector picks the network the mint is looked up on (most real tokens are on mainnet-beta).

This page must be served over HTTP

LaunchGuard is built from ES modules, which browsers refuse to load from a file:// page, so the buttons above cannot work when the file is opened directly. Serve this folder instead, for example python3 -m http.server 8000 or npx serve ., then open the http://localhost address it prints.

Verify a report

Paste a report JSON (from a report's "Copy report JSON" button) or a memo text carrying an h= digest. Report JSON is verified by recomputing its SHA-256 digest from the canonical form; memo text is compared against the digest of the report currently shown above, and its mint/score/band fields are cross-checked against that report. One outcome to know in advance: FIELD MISMATCH means the memo's digest matches the displayed report but its printed mint/score/band fields disagree with it — in plain words, the memo text and the report do not describe the same result, so do not trust that memo for this report.

LaunchGuard is an informational screening tool, not financial advice.
